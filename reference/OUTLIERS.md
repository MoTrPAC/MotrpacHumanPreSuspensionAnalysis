# List of outliers designated by the Pre-CAWG working group.

Data object combining outlier forms from each omic-analyst. The process
for flagging a sample is described in more detail in the methods, but,
generally, samples that were \>3x IQR in the first 3 principal
components were flagged and manually reviewed. Differs by ome.

## Usage

``` r
OUTLIERS
```

## Format

An object of class `data.frame` with 154 rows and 4 columns.
