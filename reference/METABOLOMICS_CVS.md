# Metabolite Coefficients of Variation

Metabolite coefficients of variation. Each coefficient of variation per
platform was measured on reference standards that were processed through
each platform. For more information, see the QC Notebook in the
precovid-analyses repository

## Usage

``` r
METABOLOMICS_CVS
```

## Format

A `data.frame` object with description of tissue, platform, and whether
or not a given platform is lowest CV.
